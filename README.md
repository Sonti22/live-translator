# Live Translator — синхронный переводчик для звонков

Интерфейс в духе Transync AI, движок — OpenAI `gpt-realtime-translate`.

- **Ты говоришь по-русски** → собеседник слышит английский голос (через виртуальный микрофон VB-Cable). Голос подстраивается под твой тон.
- **Собеседник говорит по-английски** → ты видишь русский перевод текстом (и его оригинал).
- Работает с любым приложением для звонков: Zoom, Telegram, WhatsApp, Discord, Meet, Teams.

## Запуск
- **`dist\LiveTranslator.exe`** — готовая программа, Python не нужен. Собрать заново: `build_exe.bat`.
- или **`start.bat`** — запуск из исходников (нужен Python 3.10+).
- `start_console.bat` — консольная версия без окна.

## Один раз
1. Ключ OpenAI: platform.openai.com → API keys, пополнить баланс (от $5).
   Вставить в программе: ⚙ Настройки → Ключ OpenAI. Хранится в `.env` рядом с программой.
2. Установить VB-Cable (vb-audio.com/Cable), если его нет.

## Каждый звонок
1. Включить VPN (OpenAI блокирует РФ). Системный прокси подхватывается сам.
2. В приложении звонка выбрать **микрофон: CABLE Output (VB-Audio Virtual Cable)**. Динамики — обычные.
3. Надеть наушники, нажать **▶**.

## Что есть в окне
| Элемент | Что делает |
|---|---|
| **Микс ›** | Источники звука: звук компьютера (собеседник), микрофон, куда идёт твой переведённый голос |
| **▶ / ■** | Старт и стоп. После стопа запись разговора сохраняется автоматически |
| Таймер и шкала | Время сессии и громкость |
| **Микрофон вкл/выкл** | Выключить себя; то же — **Ctrl+Alt+M** из любого окна |
| ▭ | Мини-субтитры поверх всех окон (перевод собеседника крупно) |
| 📌 | Закрепить окно поверх других |
| 📄 | Записи переводов, переведённое время и примерная стоимость |
| ⚙ | Ключ OpenAI, прокси, инструкция |
| **ru ⇄ en ›** | Режим (односторонний / двусторонний) и языки |
| 🔊 en | Озвучка перевода в звонок, громкость, «слышать себя» |
| **…** | Размер шрифта, перевод сверху, одна/две панели, «только перевод» |

## Цена и задержка
- ≈ $0.034 за минуту на каждое направление: ≈ $2 в час только твой голос, ≈ $4 в час в обе стороны.
- Задержка ≈ 0.5–1.5 с: модель начинает говорить, не дожидаясь конца фразы. Быстрее — VPN-сервер ближе к США/Европе и проводной интернет.

## Ограничения модели
- Словарь терминов и контекст («ИИ-ассистент» в Transync) модель пока не поддерживает.
- Выбора голоса нет: голос перевода подстраивается под говорящего автоматически.

## Файлы
- `app.py` — окно (pywebview), `ui/` — интерфейс, `live_translator.py` — движок и консольный режим.
- Рядом с программой создаются: `.env` (ключ), `settings.json`, `records/` (записи), `live_translator.log` (журнал — пришли его, если что-то не работает).
