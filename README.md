# Live Translator — синхронный переводчик для звонков твоим голосом

Аналог Transync AI (интерфейс и функции) с лучшим из JotMe, Sokuji и LiveTranslate.

- **Ты говоришь по-русски** → собеседник в Meet / Zoom / Telegram / WhatsApp / Teams слышит английский
  **твоим клонированным голосом** через виртуальный микрофон VB-CABLE.
- **Собеседник говорит по-английски** → ты видишь русский перевод текстом (и оригинал).
- Перевод начинается посреди фразы, не дожидаясь её конца (Transync ждёт конца предложения).

## Запуск
- **Ярлык «Live Translator»** на рабочем столе и в меню «Пуск» — ставит `install.bat`
  (копирует `dist\LiveTranslator.exe` в `%LOCALAPPDATA%\Programs\Live Translator`; для обновления
  после новой сборки просто запустите `install.bat` ещё раз — ключи, настройки и записи сохранятся).
- Собрать заново: `build_exe.bat`.
- или **`start.bat`** — из исходников (Python 3.11+). `start_console.bat` — консольная версия.

## Один раз
1. **VB-CABLE** (бесплатно): vb-audio.com/Cable → установить → перезагрузить ПК. Без него ▶ не запустится,
   программа покажет инструкцию.
2. **Ключ Soniox** (основной движок): console.soniox.com → API keys → ⚙ Настройки → «Soniox».
   По желанию — ключ **OpenAI** (ИИ-протокол после звонка, запасной движок).
3. **Твой голос**: 🔊 → «Записать голос» → прочитать текст 25 секунд → «Создать клон» → «▶ Прослушать».
4. **ИИ-ассистент** (по желанию): имена, компании, термины в виде `Акопян Сурен = Suren Hakobyan`
   и пара предложений о себе / теме звонка — перевод станет точнее.

## Каждый звонок
1. Включи VPN, если сервисы не открываются напрямую (прокси системы подхватывается сам). Сервер VPN лучше
   в Европе: ⚙ Настройки → «Интернет» → **«Проверить связь»** покажет задержку до сервисов и страну выхода.
2. В приложении звонка выбери **микрофон: CABLE Output (VB-Audio Virtual Cable)**, динамики — обычные.
3. Надень наушники и нажми **▶**. При первом запуске программа попросит проверить, что звонок слышит только
   кабель (Ctrl+Alt+M → индикатор микрофона в Zoom не двигается). Выключить себя — кнопка «Микрофон» или
   **Ctrl+Alt+M** из любого окна; **Ctrl+Alt+Space** — «я закончил»: перевод фразы звучит сразу.

## Возможности
| | |
|---|---|
| Движки | **Soniox** (по умолчанию: перевод посреди фразы, клон голоса, словарь и контекст) · **OpenAI** gpt-realtime-translate (голос модели или клон Cartesia; голос модели менее скрытный — русское слово в его озвучке не отфильтровать) |
| Голос | мой клон · встроенные голоса с прослушиванием · синтез Soniox, Cartesia (быстрее на ~0,2 с) или Inworld · скорость (1.1 по умолчанию) · громкость · «слышать себя» |
| Быстрее | автоускорение голоса, срез пауз синтеза, мгновенные короткие ответы, быстрое завершение фраз (расширенные настройки) |
| Скрытность | в звонок идёт только синтезированный английский: перевод не стартует, если микрофон или вывод Windows — кабель; «слышать себя» в кабель пропускается; прослушивание голоса — только в наушники |
| Режимы | Двусторонний · Только я говорю · Только слушаю |
| ИИ-ассистент | ключевые слова `термин = перевод` и контекст (как в Transync) |
| ИИ-протокол | после ■: заголовок, кратко, решения, задачи; экспорт .md (нужен ключ OpenAI) |
| Экран | одна / две панели, «только перевод», размер шрифта, мини-субтитры поверх окон с паузой |
| Записи | каждая сессия сохраняется, переведённое время и примерная стоимость |
| Задержка | показывается после каждой фразы: «задержка ≈ 0.8 с» |

## Цена (примерно)
- Soniox: ~$0.12 в час на каждое направление + ~$0.7 за час озвученной речи (ты говоришь примерно
  половину звонка, так что ~$0.35 в час). Итого двусторонний звонок ≈ $0.6 в час.
- Голос Cartesia вместо Soniox: ~$2.7 за час речи; Inworld: ~$0.9.
- OpenAI: ~$2 в час на каждое направление. ИИ-протокол: центы за звонок.

## Файлы
- `app.py` — окно (pywebview), `ui/` — интерфейс, `live_translator.py` — движок и консоль,
  `soniox_engine.py`, `voice_clone.py` (Cartesia), `meeting_notes.py`, `netcheck.py` («Проверить связь»).
- `tools/latency_test.py` — реальный замер задержки: таблица по кускам фразы, `--wav`, `--repeat N`,
  `--provider soniox|cartesia|inworld`, `--speed`, `--region eu`, `--done`; голос и ускорители
  (`--no-boost`, `--no-trim`, `--no-phrases`, `--no-finalize`) — как в установленной программе, если не заданы.
- Рядом с установленной программой (`%LOCALAPPDATA%\Programs\Live Translator`): `.env` (ключи), `settings.json`, `records/` (записи и протоколы), `voice_sample.*`,
  `live_translator.log` — журнал; пришли его, если что-то не работает.
