# Live Translator — переводчик для звонков

- **Ты говоришь по-русски** → собеседник слышит английский голос (через виртуальный микрофон VB-Cable).
- **Собеседник говорит по-английски** → ты видишь русский текст в окне программы (и его английский оригинал).

Работает с любым приложением для звонков: Zoom, Telegram, WhatsApp, Discord, Meet, Teams.
Движок: OpenAI `gpt-realtime-translate` (синхронный перевод, начинает говорить, не дожидаясь конца фразы).

## Один раз
1. Ключ OpenAI: platform.openai.com → API keys. Пополнить баланс (от $5).
2. Создать рядом со скриптом файл `.env` с одной строкой:
   `OPENAI_API_KEY=sk-...`
3. Установить VB-Cable (vb-audio.com/Cable), если его нет.

## Каждый звонок
1. Включить VPN (OpenAI блокирует РФ). Системный прокси подхватывается сам.
2. Запустить `start.bat`.
3. В приложении звонка выбрать **микрофон: CABLE Output (VB-Audio Virtual Cable)**.
   Динамики/наушники — обычные.
   - Telegram Desktop: Настройки → Звонки → Микрофон.
   - Zoom: Настройки → Звук → Микрофон.
4. Говорить по-русски. В окне:
   - `Я` — что распознано из твоей речи, `Я → EN` — что услышал собеседник, `задержка ≈ 0.8 с` — через сколько он начал слышать перевод;
   - `Он` — его английский, **`Он → RU`** — перевод на русский (жёлтым).
5. Наушники обязательно — иначе звук собеседника попадает в микрофон.

## Режимы
- `start.bat --no-listen` — только твой голос → английский, без субтитров собеседника.
- `start.bat --monitor` — слышать свой перевод в наушниках.
- `start.bat --listen "Наушники"` — если звонок звучит не в устройстве по умолчанию.
- `start.bat --passthrough` — без перевода, голос напрямую в кабель (проверить, что звонок тебя слышит).
- `start.bat --list` — список аудиоустройств; `--in <имя>` / `--out <имя>` — выбрать другие.
- `start.bat --proxy socks5h://127.0.0.1:10808` — прокси вручную; `--proxy none` — без прокси.
- `--lang` / `--their-lang` — другие языки (по умолчанию en / ru).

## Цена и задержка
- ≈ $0.034 за минуту на каждое направление: ≈ $2 в час только твой голос, ≈ $4 в час в обе стороны.
- Задержка ≈ 0.5–1.5 с: переводчику нужно услышать смысл фразы. Меньше задержка — VPN-сервер ближе к США/Европе и проводной интернет.
