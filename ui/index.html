              Интернет

              Как подключить к звонку

              1. Включите VPN — OpenAI не работает из РФ напрямую.
              2. В Zoom / Telegram / WhatsApp / Discord выберите микрофон CABLE Output (VB-Audio Virtual Cable).
              3. Наденьте наушники и нажмите ▶.
              4. Ctrl+Alt+M — выключить/включить микрофон из любого окна.
