                Как подключить к звонку

                1. Включите VPN — сервисы перевода могут не работать из РФ напрямую.
                2. Один раз запишите свой голос: 🔊 → «Записать голос» → «Создать клон».
                3. В Zoom / Telegram / WhatsApp / Discord выберите микрофон CABLE Output (VB-Audio Virtual Cable).
                4. Наденьте наушники и нажмите ▶.
                5. Ctrl+Alt+M — выключить/включить микрофон из любого окна.
                6. Ctrl+Alt+Space — «я закончил»: перевод фразы звучит сразу, не дожидаясь паузы.

                Нужен виртуальный микрофон

                Перевод попадает в звонок через бесплатный драйвер VB-CABLE: программа «говорит» в него, а Meet/Zoom слышат его как микрофон.
                1. Скачайте VB-CABLE:
                2. Распакуйте архив и запустите VBCABLE_Setup_x64.exe от имени администратора → Install Driver.
                3. Перезагрузите компьютер и снова откройте Live Translator.
                4. В Meet / Zoom / Telegram выберите микрофон CABLE Output (VB-Audio Virtual Cable).
                5. Проверьте до входа в звонок: Zoom → Настройки → Звук (Meet: Настройки → Аудио). Нажмите Ctrl+Alt+M и скажите пару слов — индикатор входного уровня не должен двигаться.

                Проверка перед звонком

                Собеседник должен слышать только английский перевод, а не ваш настоящий микрофон. Проверьте до начала звонка — один раз после запуска программы.
                Микрофон Windows по умолчанию: —
                1. В Zoom / Meet / Telegram выберите микрофон CABLE Output (VB-Audio Virtual Cable).
                2. Сделайте это до входа в звонок: Zoom → Настройки → Звук (Meet: Настройки → Аудио). Нажмите Ctrl+Alt+M и скажите пару слов — индикатор входного уровня не должен двигаться. Двигается — звонок слышит ваш настоящий микрофон: выберите там CABLE Output. Уже в звонке — ничего не говорите, только проверьте, что там выбран CABLE Output.
                3. Снова нажмите Ctrl+Alt+M, чтобы включить микрофон программы.
